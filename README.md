# 电源树编辑器 · Power Tree Editor

> **⚠️ 当前为「早期尝鲜版」（Early Access）**
> 核心功能已可用，但仍有若干已知问题 —— 尤其是**输入框打字会失焦**和**导入不合规 JSON 会白屏**这两个。
> 全部已知问题都列在 [KNOWN_ISSUES.md](./KNOWN_ISSUES.md) 里，带成因和修法，欢迎直接提 PR。

一个**零依赖、单文件**的电源树（Power Tree）可视化编辑工具。

把「市电 → 适配器 → 板级入口 → DCDC → LDO → 负载」这条链拆成方块，逐个填电压 / 电流 / 连接器额定电流，
工具会自动算出**哪一级是瓶颈**并标红 —— 用来在设计阶段就把"接口耐流不够"这种坑提前揪出来。

单个 HTML 文件，双击即用，不需要 node、不需要构建、不需要联网。

---

## 两个版本

| 文件 | 形态 | 适合 |
|---|---|---|
| `index.html` | **树版**：层级嵌套，自动布局 | 顺着一个方向查下来的供电链；结构稳定、改动少 |
| `graph.html` | **连线版**：Blender / 达芬奇式节点图，**推荐** | 需要自由拖放、并联汇流、反复改拓扑 |

连线版把数据模型换成了「扁平节点表 + 边表」，所以：

- **起点**不再是特殊身份 —— 没有入线的节点就是起点，拔线/接线自由切换
- **多轨并回单轨**天然成立（多条线指向同一个输入口即可），方块上会标「N 路汇入」
- 渲染从"整块重建"改成 diff 增量更新，顺带修掉了树版「要刷新才出来」和「打字掉焦点」的问题

详见 [DESIGN_graph.md](./DESIGN_graph.md)。

## 快速开始

```
git clone https://github.com/Xun-Yu-WX/Visual-editor-for-power-supply-trees.git
```

然后**直接双击 `graph.html`**（连线版，推荐，已适配触摸/移动端），或 `index.html`（树版）也行，右键用浏览器打开即可。

也可以拖进任意一个静态托管（GitHub Pages / Netlify / Vercel），因为整个项目就是几个 HTML 文件。

## 界面说明

| 区域 | 作用 |
|---|---|
| 顶部按钮 | 新分区 / 导出 JSON / 导入 JSON / 恢复示例 / 深浅色切换 |
| 左侧画布 | 树状图，点任意方块选中并编辑 |
| 右侧面板 | 当前选中节点的参数表单，改完即时生效 |

编辑会自动存到浏览器 localStorage，**不会自动清空隐私模式除外**。

## 字段含义

| 字段 | 说明 |
|---|---|
| 输入 V / 输出 V | 电压，纯展示 + 算功率用 |
| 持续 A | 正常工作电流 |
| 峰值 A | 堵转、启动、瞬时峰值 |
| 连接器 / 封装 | 随便写，用来提醒自己这是什么座子 |
| 额定电流 A | **关键字段**：这个节点能长期承受多大电流。填 `99` 表示不受限（比如纯铜皮） |

### 颜色判定规则

| 颜色 | 条件 |
|---|---|
| 🟢 绿 | 额定 ≥ 持续 且 额定 ≥ 峰值 |
| 🟠 橙 | 额定 ≥ 持续，但额定 < 峰值（长时间会发热） |
| 🔴 红 | 额定 < 持续（**必须换粗线 / 换座子**） |

> 常见参考值：普通 2.54mm 排针单针约 1.5–2A，杜邦跳线帽约 2A，XH2.54 约 3A，XT30 约 30A。
> 具体以你手上器件的 datasheet 为准，这里的数值只是常见经验值兜底。

## 导出格式

点击「导出 JSON」会下载一个文件，结构大致如下：

```json
{
  "sections": [
    {
      "name": "① 主电源链",
      "roots": [
        {
          "id": "n12345",
          "label": "12V 5A 适配器",
          "type": "converter",
          "vin": "220",
          "vout": "12",
          "i": "5",
          "ipk": "5",
          "conn": "适配器自带输出线",
          "rating": "5",
          "note": "隔离电源",
          "children": [ { "...": "递归子节点" } ]
        }
      ]
    }
  ],
  "theme": null
}
```

`type` 取值：`source` / `converter` / `connector` / `device` / `load`（目前只做样式区分，不影响计算）。

导出的 JSON 可以直接丢进 README 或文档里，也可以发给队友导入。

## 适用场景

- 画 PCB 之前理清电源走向，别到最后才发现某个座子扛不住
- 机器人 / 航模 / 小车多路供电（逻辑电 & 动力电分离）的整理
- 参加科创比赛时，把评审问到的"你这个座子过 3A 行不行"提前答掉

## 已知边界

- 数据是浏览器本地存储，**换浏览器 / 清缓存会丢**，重要结果记得导出 JSON
- 没有多标签页同步，两个人改同一棵树会各改各的
- 校验只做"持续 vs 额定"和"峰值 vs 额定"，不做线宽、压降、温升计算
- 纯前端，没有撤销/重做（Undo），删节点前会弹确认框
- 📱 **触摸/移动端**：连线版 `graph.html` 已处理触摸拖拽与连线（禁用了浏览器手势抢占、并监听 `pointercancel`），手机上可正常拖放与接线；树版 `index.html` 面板为桌面宽度，窄屏会比较挤。
